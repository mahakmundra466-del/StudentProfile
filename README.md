Student Profile

A simple and responsive student profile webpage built using HTML and CSS to showcase student information, education, skills, achievements, and interests.

About the Project

This project is a student profile webpage designed to present academic and personal information in a clean and organized format.

I created this project as part of my web development learning journey to practice HTML structure and CSS styling.

Features

- Student introduction
- Education details
- Skills
- Achievements
- Hobbies and interests
- Contact information
- Clean and user-friendly design
- Responsive layout

Technologies Used

- HTML5
- CSS3

- Styling webpages using CSS
- Organizing information into different sections
- Creating a clean and user-friendly webpage
- Publishing and managing projects using GitHub
